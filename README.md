# Data Structures Implementation

This project implements several data structures and algorithms in C, including:

- **ArrayList**: A list impl by array
- **ArrayStack**: A stack impl by array
- **PointerList**: A list impl by pointer
- **PointerStack**: A stack impl by pointer
- 
Additionally, this project includes some testing code to measure the performance of these data structures.

## Table of Contents

- [Overview](#overview)
- [Installation](#installation)


## Overview

This project provides implementations of various data structures with the goal of demonstrating their functionality and performance characteristics. Each data structure is implemented both with arrays and linked lists to highlight different approaches to managing data.
